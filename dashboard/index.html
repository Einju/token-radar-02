Research & Methodology Notes

1. Quadratic Valuation Framework

The token radar v2 model establishes a baseline valuation framework for pre-token protocols by regressing market capitalization against Total Value Locked (TVL) across 128 traded comparables using a quadratic logarithmic OLS specification: log10(mcap) = intercept + b1·log10(TVL) + b2·log10(TVL)² + growth + age + category adjustment. The quadratic term captures scale-dependent premium absorption as protocol TVL grows.

2. Three Held-Out Validation Tests

Model robustness is evaluated across three strict test suites: Leave-One-Out (LOO median absolute log error 0.560, 32.8% within 2×), Repeated 80/20 Split (median error 0.552, 32.8% within 2×), and Walk-Forward Time-Split (median error 0.788). In addition, the blended token odds model (0.5 logistic + 0.5 peer record) achieves a robust 5-fold CV AUC of 0.733.

3. Farmability & Non-Farmable Protocol Handling (New in v2)

Every board row now features an explicit `farmable` boolean. Centralized exchanges (CEX) and cross-chain bridges lack an on-chain interaction path that earns token airdrops. Consequently, non-farmable protocols display a prominent "NOT FARMABLE" badge, their expected value (EV) is listed as "n/a — no farm path", and their action steps provide honest guidance against depositing funds for token farming.

4. Three Honest Research Findings (Limitations & Insights)

(a) Model Ceiling (~3.6× median error): The underlying market cap to TVL spread spans six orders of magnitude (−3.60 to +2.60 in log10 space). This extreme dispersion represents structural asset diversity rather than fitting error; no regression specification can eliminate this fundamental variance ceiling.

(b) The Ratio-Filtering Trap: Filtering out extreme comparables (|log10(mcap/TVL) - median| ≤ 1.0) artificially inflates in-sample and test-set metrics (making R² appear >0.6), but when applied strictly to training data and evaluated on all 128 comps, held-out error actually worsens (LOO error rises from 3.52× to 4.04×). We avoid ratio-filtering entirely.

(c) Survivor Bias & Growth Sign: Token odds exhibit an age correlation that reflects historical survivorship (early protocols launched with tokens). Furthermore, the fitted 7d growth coefficient is negative (−0.0162), indicating that rapid short-term TVL growth is mean-reverting in this snapshot cross-section. Both phenomena are modeled and disclosed transparently.
